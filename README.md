# Framehaven

Create beautiful fullscreen slideshows from your favorite photos and music.

## What it does

Framehaven turns photo collections into personal slideshows on your Mac. Create a slideshow, add pictures from folders or Photos—including a complete Photos album—and choose how they should be presented.

You can arrange pictures by file name or date, shuffle them, adjust the time per picture, enable the Ken Burns effect, and repeat the slideshow in an endless loop. Add a soundtrack using audio files from Finder or a playlist from your Music library.

During playback, Framehaven keeps every picture fully visible and provides controls for pausing, moving between pictures, closing the slideshow, and choosing an AirPlay audio device. To display the complete slideshow on another screen, use Screen Mirroring in Control Center.

Framehaven shows progress while it prepares pictures, imports Photos content, or loads a Music playlist. The cycle duration is displayed beside the Play button so you can see the complete running time before playback begins.
