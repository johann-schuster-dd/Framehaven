# Framehaven Support

Come here for everything you need to create and enjoy slideshows in Framehaven.

## Slideshows

### Create a Slideshow

1. Open Framehaven.
2. Click the plus button in the toolbar.
3. Select the new slideshow in the sidebar.
4. Enter a name and, if you like, choose a different symbol.
5. Add pictures and adjust the playback settings described below.

Your changes are saved automatically.

### Duplicate or Delete a Slideshow

Open the context menu for a slideshow in the sidebar, then choose "Duplicate" or "Delete". You can also delete a slideshow using the sidebar's standard delete action.

Deleting a slideshow cannot be undone.

## Pictures

Framehaven offers three ways to add pictures.

### Add Picture Folders

1. Open the slideshow.
2. In the "Picture Folders" card, click "Add Picture Folders…".
3. Select one or more folders and click "Add Folders".

Framehaven keeps a reference to each selected folder. Your original pictures stay in place and are not copied into the app. If a folder is moved, deleted, or becomes unavailable, add it again from its new location.

### Add from Photos

1. In the "Picture Folders" card, click "Choose Pictures from Photos…".
2. Select one or more pictures.
3. Confirm the selection.

Framehaven imports copies of the selected pictures into its application support folder. If an item is available only in iCloud and cannot be imported, download it in Photos and try again.

### Add an Entire Photos Album

1. In the "Picture Folders" card, click "Add an Entire Album…".
2. Allow Photos access if macOS asks.
3. Search for and select an album.

Framehaven imports every picture in the album and shows progress while local or iCloud items are prepared. Videos in the album are ignored.

## Playback

Use the "Playback" card to configure the slideshow:

- "Order" sorts pictures by file name, reverse file name, newest first, oldest first, or randomly.
- "Time per Picture" controls how long each picture remains on screen.
- "Ken Burns Effect" enables a gentle zoom during playback.
- "Transition Duration" controls the crossfade between pictures.
- "Endless Loop" starts again after the last picture instead of closing the slideshow.

Click "Play Slideshow" or the Play button in the toolbar to begin.

The estimated cycle duration appears directly beside the Play button and updates when the picture count or time per picture changes.

During playback, use the on-screen controls or the left and right arrow keys to move between pictures. You can pause or resume the slideshow and press Escape to close it. Moving the pointer or clicking the slideshow reveals the controls again.

Pictures are displayed without cropping, so the entire image remains visible.

## Soundtrack

### Add Audio Files from Finder

1. In the "Soundtrack" card, click "Choose Music…".
2. Choose "From Finder…".
3. Select one or more audio files.

The songs play in order and repeat for the duration of the slideshow.

### Choose a Playlist from Music

1. In the "Soundtrack" card, click "Choose Music…".
2. Choose "Playlist from Music…".
3. Allow Music access if macOS asks.
4. Select a playlist.

Choosing Finder audio replaces the selected Music playlist, and choosing a Music playlist replaces the Finder audio selection.

If a playlist is unavailable, make sure Music access is allowed in System Settings and that cloud-hosted songs are available for playback.

Framehaven displays a loading indicator while it prepares a Music playlist for playback.

## AirPlay and External Displays

The playback controls include an AirPlay button for compatible audio devices. To show the complete slideshow on another display or Apple TV, open Control Center and use Screen Mirroring.

## Troubleshooting

### No Pictures Found

Make sure the selected folders are still available and contain supported image files. If a folder was moved or renamed, remove its old entry and add it again.

### Media Could Not Be Added

Cloud-only files may need to be downloaded before Framehaven can create a lasting reference or import them. Download the affected items, then try again.
